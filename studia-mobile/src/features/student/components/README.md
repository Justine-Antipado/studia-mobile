# student components

Pieces used by more than one student screen: `class-card`, `task-row`,
`quiz-question-card` (take + review modes), `planner-block-card`, `video-player` (the only
place expo-video is used). `course-detail/` holds that screen's five tabs.
Attachment and comment rows are shared with the instructor side and live in
`shared/components/ui`.
