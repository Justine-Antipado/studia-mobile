# student components

Pieces used by more than one student screen: `class-card`, `task-row`,
`quiz-question-card` (take + review modes), `planner-item-row`, `priority-task-card`, `date-strip`.
Lesson videos are links
(`VideoLinkCard` in `shared/components/ui`), so no screen uses a video player. `course-detail/`
holds that screen's five tabs.
Attachment and comment rows are shared with the instructor side and live in
`shared/components/ui`.
